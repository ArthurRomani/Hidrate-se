# 💧 Hidratese

Aplicativo mobile desenvolvido em React Native que ajuda os usuários a encontrar pontos de **água potável gratuitos** disponíveis pela cidade.

## 📱 Visão Geral

O **Hidratese** tem como objetivo incentivar a hidratação e reduzir o consumo de plástico, permitindo que qualquer pessoa encontre facilmente locais onde pode encher sua garrafinha com água limpa e segura.

## ✨ Funcionalidades

- 📍 Mapeamento de bebedouros e fontes públicas
- 🗺️ Visualização dos pontos no mapa
- ⭐ Avaliação e comentários dos usuários
- 🔍 Busca por bairros ou locais específicos
- 🔄 Atualização em tempo real dos pontos

## 🧰 Tecnologias Utilizadas

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [React Navigation](https://reactnavigation.org/)
- [React Native Maps](https://github.com/react-native-maps/react-native-maps)
- [Firebase / AsyncStorage] para persistência de dados locais
- [Geolocalização](https://docs.expo.dev/versions/latest/sdk/location/)
